Düzeltme 967740b243f7b7efc43fad46a490cfd531c22ea5 için PR42225616659 ve push42225610348 koşularının tamamı, Windows dahil PASS. Kurulu uygulama dosyaları 51923ef5 ile aynı; değişiklik yalnız test/kanıt dosyalarında olduğundan yeniden başlatılmadı. Yerel bütün ekran testlerini alt süreçli runner ile başlatma denemesi offline guard tarafından reddedildi; guard değiştirilmedi ve o koşu PASS sayılmadı. Önceki gerekçesiz module mock alt süreç hatası eski dış günlükte korunur.
