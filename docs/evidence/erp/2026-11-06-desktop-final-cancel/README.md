# K05-11 — gerekçeli kesin satış iptali, kurulum öncesi kaynak hazırlığı

Kapalı private servis kayıtlı TLS writer ve normal auth verifier ile kendi SERIALIZABLE işlemini açar; istemci işlem nesnesi, tutar, hesap veya yetki sağlayamaz. Komut yalnız UUID, fiş kimliği, beklenen sürüm ve gerekçedir. Güncel sales.view + sales.cancel aynı fiziksel SQL işleminde doğrulanır. DB/SPID/CURRENT_TRANSACTION_ID ve işlem durumu yetki öncesi/sonrası ve scope kontrollerinde aynı kalmalıdır. Native iptal mevcut invoiceDraftService.cancelSalesInvoice üzerinden çağrılır. Normal auth binder lease'i commit/rollback sonuna kadar tutar.

Özgün iki stok çıkışı, kalemler, DISPATCHED rezervler, tek cari hareketi ve seçilmiş hesap kilitli okunur. Güncel kur/fiyat kullanılmaz. Native iptalin yalnız özel sahiplenilmiş çağrısında iskonto sonrası kaydedilmiş TRY stok vektörü terslenir. Dövizli alt hesap ana cari dövizinden farklıysa eski ana bakiye korunur; aynıysa iki bakiye aynı net hesap tutarıyla azaltılır. Native cari amount/account_amount/amount_try pozitif görüntü, balance_effect negatif yöndür. Posting SQL'i özgün hareketlerin korunmasını, iki stok ters kaydını, cari/audit/gerekçe/UUID ve seçili hesap CAS'ini karşılaştırıp workflow sürümünü CANCELLED yapar. Bu T-SQL henüz gerçek uygulama writer'ıyla çalıştırılmadı.

Kalıcı SQL journal actor/UUID/fiş/komut hash'i ve sonuçla bağlanır; aynı istek kayıp commit cevabından sonra ikinci etki üretmeden replay olur. Gerekçe veya sürüm değişmiş aynı UUID reddedilir. Kısmi native/posting hatasında SQL geri alınır. Çıplak desktopPrivateSale bayrağı yetki oluşturmaz. Eski genel/native/selected SOURCE yolları aynı kalır; native dosya farkı yalnız cancelSalesInvoice gövdesindedir. B6 seçili-kalem gövdesi SHA235d4119… ve özgün SQL SHA17a2646f… byte-identical; bütün dosya pini7b8dc7a1… olarak açık kanıt zinciriyle güncellendi. [Pin kanıtı](native-source-pin-proof.json). B6 SQL çalıştırılmadı.

Aktarım günlüğü yokken eski assertInvoiceNotExported no-op dönüşü başarı kanıtı olarak kullanılmaz. Yeni özel kontrol yalnız sabit V5 günlük yolu, tam DBGUID/env kimlik dosyası ve sonlu kapalı TEST env'inde ilerler; eksik, bozuk, yabancı veya reparse hedefte ret verir. Kurulum bu yolu/kimlik dosyasını henüz oluşturmadı. Export claim ile cancellation claim aynı wx per-invoice mutation lock'u kullanır. Önceden export attempt/verified varsa iptal başlamaz; iptal SQL etkisinden önce kalıcı cancellation fence yazar. Bu fence SQL rollback veya kayıp ACK sonrasında da korunur ve stale hazırlanmış export gönderilemez. Public inspect/status/preview fence veya kalmış lock için REVIEW_REQUIRED gösterir; lock otomatik devralınmaz. Farklı iptal UUID/actor/hash aynı fence'i kullanamaz. Fence'in kaldırılması otomatik retry/resolve işlemi değildir; manuel yetkili inceleme gerektirir.

64 kaynak dosyasında364 test PASS; son auth-binder genişletmesi ayrıca13 test PASS. Gerçek native iptal motoru sentetik SQL transaction fixture'ında dört döviz/ana hesap durumuyla çalıştı: net iskontolu stok vektörü, seçilmiş hesap, ana bakiye korunması, rol/queue/dönem/snapshot/export retleri, kısmi hata rollback, kalıcı fence, kayıp ACK ve aynı UUID replay. Gerçek geçici filesystem testleri iki journal örneğinin export/cancel yarışını, önceki attempt/verified retlerini, aynı proof retry'ını, bozuk kayıt ve terk edilmiş kilidin korunmasını doğruladı. İlk geniş koşudaki yeni statik logger kodu kaydı düzeltildi; bir route child açıklamasız kapanışı assertions korunarak ikinci tam koşuda geçti. İlk hata günlüğü silinmedi. Bağımsız salt okunur kaynak incelemesinde bildirilen export no-op ve yanlış public status P2'leri giderildi; son dar incelemede yeni P1/P2 yok. Bunlar kurulum, gerçek SQL DML veya insan kabulü değildir.

Salt okunur Windows yönetici sorgusu önceki gerçek schema4 hedefinde sekiz sonuç kümesini doğruladı: fiş13, TRY51.2160, özgün stok25.6080 +25.6080. Sorgu SHAff266e8c…; uygulama writer/auth/export/native iptal deneyi değildir. Güncel kurulu kaynak aef16a63 / paketdf4440b7… halen schema4'tür. Yeni kod pakette yoktur; role sales.cancel, SQL GRANT, DDL, parola, servis veya ticari veri değişmedi. V4 auth allowlist'i sales.cancel'i hâlâ reddeder.

Kalan bağlı işler: normal iptal route/ekranı, kalıcı istemci isteği ve resolve sözleşmesi; ayrı sonlu V5 profil/izin guard'ı; rollback-first kurulum derleyicisi/paketi ve sabit kimlikli export journal hazırlığı; ardından tam kaynak/CI, yetki kapsamı onayı, kontrollü TEST kurulum ve mevcut fiş üzerinden tek normal ekran iptali. Gerekli yeni güvenlik kapsamı üç sales_invoices UPDATE sütunu (cancelled_at/cancel_reason/updated_by), terminal_sync_queue SELECT ve yalnız deneme rolüne sales.cancel'dir. Genel tablo UPDATE veya yönetici yetkisi gerekmiyor. Komut/resolve CHECK kısıtları ve profil sürümü de açıkça geçişe bağlanmalı. Bunların hiçbirisi uygulanmış değildir.
