SQL rollback veya kayıp ACK fence'i otomatik silmez. Public durum fence/kalıcı kilit için REVIEW_REQUIRED'dır. Resolve SQL kaydı yokken fence bulursa pending korunur, yeni UUID açılamaz ve ekran inceleme ister; yalnız fence yoksa DURABLE_NO_COMMIT tombstone verilir. Aynı actor/UUID/gövde hash'i replay tek etki üretir; farklı gerekçe/sürüm aynı UUID'yi kullanamaz.
