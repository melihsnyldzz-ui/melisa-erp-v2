# Melisa Hub: mevcut izole web üzerinde güvenli giriş

Hub, mevcut iş ekranlarını veya kimlik sistemini değiştirmez. `/melisa-hub/` statik portalı, aynı web sunucusunun mevcut Host/socket korumasından sonra servis edilir. ERP/eğitim/el terminali relative adresler; CRM doğrulanmış mevcut hostname ve UI portu üzerinden açılır. CRM gateway/catalog/order uçları proxy edilmez. TEST125 yalnız exact eski web/API source, DB ve LIVE erişim sınırı doğrulanırsa mevcut Host5194 üzerinde açılır; yeni/uyuşmayan kimlikte kapalıdır. LIVE bağlantısı kapalıdır.

`config.json` ve `status.json` yalnız GET/HEAD; diğer yöntemler405. No-store/nosniff ve yalnız self CSP uygulanır; Origin/forwarded header olumsuzları reddedilir. Dört portal dosyası exact allowlist ile yayınlanır; özel rapor, video ve kanıt klasörü mount edilmez. Hub tarayıcı oturumu/token üretmez ve otomatik AI, ticari API veya SQL çağırmaz.

Özel runtime pin dosyası mevcut API/native source, CRM source/HTML SHA ve sekiz doğrulanmış ders görselinin SHA değerlerini içerir. Startup argümanındaki mevcut operasyon config'i değiştirilmez. İç health okumaları sabit loopback adreslerine kısa timeout/redirect:error ve boyut sınırıyla yapılır. Kimlik/kopya/DB/T1/LIVE erişimi veya CRM freshness/paket HTML'i uyuşmazsa durum `unknown`; bağlantı hatasında `unreachable`. Yanıt yalnız erişilebilirlik ve `acceptance:pending` içerir; DB/login/source/kopya/seal/ticari bilgiler veya ham hata içermez. Beş saniyelik cache ve eşzamanlı birleşme gereksiz tekrar okumayı önler.

`scripts/canonical/start-hub-web.ps1` yalnız web5234 için owner/Node/manifest/paket/DB02 dependency pinli Inspect/Start sağlar. Başkasının portunu durdurmaz, API/native/CRM başlatmaz; SQL veya ticari kayıt yazmaz. 11 Ekim açık kullanıcı onayıyla ayrı **Melisa-Hub-TEST-Web** görevi kuruldu: aynı kullanıcı AtLogOn/Interactive/Limited, IgnoreNew, PT0S. Action immutable paketteki `watch-hub-web.ps1` üzerinden core launcher'ı her seferinde yeniden doğrulayarak çalıştırır; core `-Watch` çağrısı rekürsif kullanılmaz. Fresh receipt/owner/node/source/commandline/creation ile yalnız kendi child'ına bağlanır. İlk çalıştırma + en çok üç retry/60 saniye tek bütçedir. Scheduler RestartOnFailure öğesi yok / RestartCount0; bütçe çoğalmaz. WindowsPS5 handle cache ve parantezli path argları korunur. Özel hata logları web dışında kalır.

Gerçek kendi child kaybı provasında yeni PID/same source/same supervisor ile 72,07 saniyede kurtarma doğrulandı; bekleme60 + tekrar pin/dependency/start kontrolü dahildir. Retry exhaustion fixture dört start/üç wait sınırını doğruladı, gerçek runtime denemesiyle karıştırılmaz. [Microsoft protokolü](https://learn.microsoft.com/en-us/openspecs/windows_protocols/ms-tsch/2ff4aa5a-7bc4-449f-bbb1-27475645867f) Scheduler retry'ı koşul/action başlangıç hatası için tanımlar; uygulamanın sonradan kapanması gözetim döngüsünde ele alınır. Görev kullanıcı girişsiz reboot sürekliliği değildir. API/native bağımlılıkları açılmadıysa fail-closed kalır; supervisor bütçesi içinde yalnız mevcut exact dependency tekrar okunur, dependency servisleri başlatılmaz. Mevcut TEST1255194 ve eski CRM62400 başlangıç görevleri DB02 için yeniden hedeflenmez. Firewall, Tailscale/Serve/Funnel/ACL/subnet/device ayarı değiştirilmez. IP değişirse exact bind/Host/CSP kapsamı açılmaz; bağlantı başarısız kalır. Kalıcı DNS/HTTPS ayrı onay ve auth/peer testleri gerektirir. Tam PC reboot/logon/IP değişimi denenmedi; cihaz ACL kararı ertelendi.

Aktivasyon: yeni temiz source paketini build et; sekiz ders PNG'sini önceki doğrulanmış paket SHA'larıyla kopyala ve yeni manifestte kaydet; yeni private launcher pinini üret; Inspect'i çalıştır. Mevcut5234 web PID/owner/paket/başlangıç zamanını ve health source'unu eşleştir. Yalnız bu web sahibini kontrollü değiştir; önceki paket/config'i sakla. Başlatma/sağlık başarısızsa yeni web sahibini doğrulayıp durdur, önceki web paketini aynı eski config ile başlat. Aktif DB'ye restore/reset yok. TEST125/API/native/CRM süreç kimlikleri aynı kalmalıdır.

Teknik HTTP/GUI sonucu kullanıcı kabulü değildir. Portalın açılması bütün modüllerin işletme veya LIVE kabulü olarak sunulmaz. Geniş insan turu ve özel rapor erişimi ayrı bekler.
