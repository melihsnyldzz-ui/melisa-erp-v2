## Recovery limits

Before any B6 business history, rollback requires the exact native inverse and
readback before the old task Action, profile and READ2b API can restart. Existing
history prevents wholesale DDL inverse. No backup restore may erase later local
movements. A commit/task result that remains unknown blocks execution, inverse,
restart and a second attempt; an authenticated audit-only path can record that
failure without issuing execution authority.

Pre-channel initialization cleanup can undo only its own genuine bootstrap:
same state/lease/native creator, no API or trade effects, own child/job confirmed
closed, exact retained before/after metadata CAS and durable inverse. Reserved
exit73 is issued only after all cleanup and lease release succeeded, bound to
the original exception reference. Text, exception Data, a PID or a JSON receipt
cannot produce it. The controller also requires its actual created process
handle, fixed source/argv and protected-state/empty-port proof before recovery.
A healthy published Current owner is not killed merely because a controller
preflight failed. An unproved failure remains blocked.
